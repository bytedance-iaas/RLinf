1. Wait for the pod, then exec in:

     kubectl rollout status statefulset/{{ include "rlinf.fullname" . }} -n {{ .Release.Namespace }}
     kubectl exec -it {{ include "rlinf.fullname" . }}-0 -n {{ .Release.Namespace }} -c rlinf -- bash

   Heads-up: the training image is ~20GB, so the first pull onto a node that has never run RLinf
   takes several minutes — a pod sitting in ContainerCreating that long is pulling, not stuck.
   Later installs on the same node start in seconds. To watch the pull itself:

     kubectl describe pod {{ include "rlinf.fullname" . }}-0 -n {{ .Release.Namespace }}

   A new gateway takes a few minutes to come up:

     kubectl get apiginstance {{ include "rlinf.fullname" . }}-apig
     kubectl get ingress -n {{ .Release.Namespace }} -o wide

   Later upgrades take no extra flags — leave apig.existingId empty and the route stays bound:

     helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values

3. Get the real URL. The host above is a routing key, not public DNS. It has an auto-assigned
   *.volceapi.com domain that kubectl cannot read:

     https://console.volcengine.com/veapig -> your instance -> Service list

   ⚠️ Do NOT verify by curling the CLB IP with a Host header: APIG answers 401 with error code
   010002 that way for every host, working ones included. Test the assigned domain instead.
